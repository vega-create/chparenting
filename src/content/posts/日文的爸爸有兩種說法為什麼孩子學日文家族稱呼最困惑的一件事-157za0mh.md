孩子學到日文家族稱呼的單元，課本上「爸爸」出現了兩個字：**父（ちち）**和**お父さん（おとうさん）**。

他問：「哪一個才對？」

兩個都對，用在不同的時候。這是日文家族稱呼跟中文最不一樣的地方，也是 N5 家族單元初學者最大的困難。這篇講為什麼有兩套、孩子先學哪一套、什麼時候要分清楚。

## 日文家族稱呼為什麼有兩套

[N5 家族單元](https://learn.chparenting.com/jlpt-n5)的老師的話寫得很直接：**自家人和他人家人的兩套說法是初學者最大的困難。先學會お父さん、お母さん這套就好，另一套之後再學。**

為什麼會有兩套？因為日文很在意「**自己人**」和「**別人**」的分別：

- 跟外人提到**自己的**爸爸，要謙虛一點：**父（ちち）**。「我爸爸是老師」→ 父は先生です。
- 提到**別人的**爸爸，要尊敬一點：**お父さん**。「你爸爸是老師嗎？」→ お父さんは先生ですか。
- **直接叫**自己的爸爸，也用 お父さん。

所以「父」是「我家的、講給外人聽的、謙虛版」；「お父さん」是「別人家的、或者直接叫、尊敬版」。

中文沒有這種分法——我爸爸、你爸爸、叫爸爸，都是「爸爸」。所以孩子的困惑是很自然的。

## 先學一套：お父さん、お母さん

不要兩套一起學。**先學 お父さん、お母さん 這一套**，理由是它用途最廣：

- 可以直接叫爸媽：お父さん！（爸！）
- 可以說別人的爸媽：お父さんは元気ですか。（你爸爸好嗎？）
- N5 階段連說自己的爸媽也可以用它，考試不會扣分。

這一套的其他成員：

| 中文 | 日文（尊敬版） |
|---|---|
| 爸爸 | お父さん おとうさん |
| 媽媽 | お母さん おかあさん |
| 哥哥 | お兄さん おにいさん |
| 姊姊 | お姉さん おねえさん |
| 弟弟 | 弟さん おとうとさん |
| 妹妹 | 妹さん いもうとさん |
| 爺爺／外公 | おじいさん |
| 奶奶／外婆 | おばあさん |

注意一件事：**日文不分爺爺和外公、奶奶和外婆**，都是おじいさん、おばあさん。這對中文母語的孩子是一個小小的驚訝——中文分得那麼細，日文竟然不分。

## 另一套：父、母，等 N4

「父、母」這一套（謙虛版），是**跟外人講自己家人**的時候用的：

| 中文 | 日文（謙虛版） |
|---|---|
| 爸爸 | 父 ちち |
| 媽媽 | 母 はは |
| 哥哥 | 兄 あに |
| 姊姊 | 姉 あね |
| 弟弟 | 弟 おとうと |
| 妹妹 | 妹 いもうと |

這一套在 [N4 的自我介紹與家庭單元](https://learn.chparenting.com/jlpt-n4)才需要真的分清楚——那個單元的老師的話是：**介紹自己家人時用父、母，問別人家人時用お父さん、お母さん。**

N5 先把第一套用熟。N4 再加第二套的時候，孩子已經有「家族稱呼」的架子，第二套只是在架子上多掛一排。**兩套一起學會混，一套一套學不會。**

## 一個容易的入口：弟弟和妹妹

有一個地方可以讓孩子提早感覺到兩套的差別，而且很簡單：**弟弟和妹妹。**

弟弟的謙虛版是「弟（おとうと）」，尊敬版是「弟さん（おとうとさん）」——只差一個「さん」。妹妹也是：「妹」和「妹さん」。

跟孩子說：「講別人的弟弟要加さん，講自己的不用。」他馬上懂——因為 さん 他已經知道是尊稱（田中さん）。從弟弟妹妹開始，他會對「兩套」有第一個感覺，之後爸媽的那組（差比較多）就不會那麼陌生。

## 在家怎麼練

- **貼家族照片，用日文標。** 爸爸的照片旁邊寫 お父さん、媽媽寫 お母さん。每天看到唸一次。
- **玩「介紹我的家人」。** 孩子拿著照片說：「これは お父さんです。」（這是我爸爸。）N5 階段用 お父さん 就好。
- **聽發音。** [N5 家族單元](https://learn.chparenting.com/jlpt-n5)每個稱呼都有發音，おとうさん 的長音（とう）、おかあさん 的長音（かあ）要聽清楚，孩子常唸短。

兩週，第一套會穩。第二套等 N4。

## 一個順便的文化點

日文為什麼要分自己人和別人？因為日本文化裡「**內和外**」的分別很重要——對自己人謙虛、對外人尊敬，是基本的禮貌。

家族稱呼是這個文化最早出現在課本上的地方。孩子在這裡感覺到的「為什麼要分」，之後學敬語、學送禮的說法、學進門要說什麼，都是同一件事。所以這一課不只是背單字，是第一次碰到日本文化的核心。

## 日文家族稱呼的第一套，怎麼在兩週內用熟

第一套八個字，不用背表，用**家裡真的有的人**練：

- 第一天到第三天：爸爸、媽媽。お父さん、お母さん。就這兩個，每天叫幾次。
- 第四天到第七天：加兄弟姊妹。家裡有誰就加誰，沒有的先不加。獨生子女可以加表哥表姊（日文也是お兄さん、お姉さん）。
- 第二週：加おじいさん、おばあさん。順便講「日文不分爺爺外公」這個小驚訝。

兩週結束，孩子能用日文說出家裡每一個人。**只練家裡有的人，是這一課最快的方法**——沒有畫面的稱呼（例如獨生子女的「妹妹」）先跳過，需要的時候再補。

## 日文家族稱呼的長音，是發音最常錯的地方

這一套稱呼有一個發音上的坑：**長音。** おとうさん的「とう」、おかあさん的「かあ」、おにいさん的「にい」、おねえさん的「ねえ」——每一個都有一個拉長的音。

孩子常常唸短：おとさん、おかさん。唸短了日本人聽起來會覺得怪，而且考聽力的時候會對不上。練的時候要求他把長音真的拉長，可以用手拉一下：「お・とう～・さん」。聽發音鍵的時候特別注意那個長音有多長。

## 日文家族稱呼跟中文比，少了什麼、多了什麼

一個順便的比較，孩子會覺得有趣：

- **日文少了**：爺爺／外公、奶奶／外婆的分別（都是おじいさん、おばあさん）；叔叔／舅舅／伯伯的分別（都是おじさん）；阿姨／姑姑／舅媽的分別（都是おばさん）。
- **日文多了**：自己人和別人的兩套（父／お父さん）。

中文在「親戚是哪一邊的」分得很細，日文在「講給誰聽」分得很細。兩種語言在意的事情不一樣。孩子看到這個對比，會對「語言反映文化」有第一個感覺。

## 什麼時候算會了

第一套會了的訊號：孩子看到家人的照片，能不假思索地用日文說出來，而且長音有拉長。這時候就可以進下一個單元，不用急著學第二套。第二套的訊號會在 N4 出現——他開始有機會「跟外人介紹自己的家人」（例如日文自我介紹），那時候「父、母」才有用武之地。
