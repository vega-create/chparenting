樂理課老師問音程：「C 到 E 是幾度？」

孩子數：「C 到 D 一個，D 到 E 一個——二度！」

錯，是三度。他很困惑：明明只走了兩步。

**音程的數法跟孩子直覺的「走幾步」不一樣，起始音要算 1。** 這是音程這一課幾乎每個孩子都會犯的第一個錯。這篇講音程怎麼數、為什麼這樣數、大小音程和協和不協和是什麼。

## 音程是什麼：兩個音的距離

[樂理的音程單元](https://learn.chparenting.com/music/basic/intervals)分四個觀念：什麼是音程、音程的計算、音程的種類、協和與不協和。

先講第一個。**音程就是兩個音之間的距離**，單位是「度」。就像兩個地方之間的距離用公里算，兩個音之間的距離用度算。

為什麼要算音程？因為音樂是音和音的關係組成的。一段旋律好聽，是因為音和音之間的距離安排得好；一個和弦是什麼感覺，取決於裡面的音程。音程是理解音樂結構的基本單位。

## 音程怎麼數：起始音算 1

單元的解說寫得很清楚：**計算音程度數時，從起始音數到目標音：C(1) D(2) E(3)，所以是三度。**

關鍵在**起始音算 1**。不是算「中間隔幾個」，是「從起點數到終點，一共經過幾個音名」。

- C 到 D：C(1) D(2) → 二度
- C 到 E：C(1) D(2) E(3) → 三度
- C 到 G：C(1) D(2) E(3) F(4) G(5) → 五度
- C 到高音 C：C(1) D(2) E(3) F(4) G(5) A(6) B(7) C(8) → 八度

孩子為什麼會從 0 開始數？因為他習慣算「走了幾步」——從 C 走到 E 確實走了兩步。但音程不是算步數，是算「碰到幾個音」。C 也算、E 也算，中間的 D 也算，三個。

一個記法：**音程像數樓層，不是數樓梯。** 從一樓到三樓，你經過一樓、二樓、三樓，三層——雖然只爬了兩段樓梯。

## 一個小規則：同一個音是一度

孩子會問：C 到 C（同一個音）是幾度？

**一度。** 因為起始音算 1，沒有往上走，就停在 1。不是零度。

這也再次說明「起始音算 1」這個規則——連同一個音都算一度，所以 C 到 D 當然是二度。孩子懂了一度，就不會再從 0 開始數。

## 在鍵盤上數，不要在腦中數

音程剛開始學，一定要在鍵盤上數，不要用想的。

手指放在 C，說「一」；移到 D，說「二」；移到 E，說「三」。三度。手指真的碰到三個鍵，「三」就有身體感。

只用白鍵數就好（黑鍵是大小音程的事，下面講）。C 到任何一個白鍵，手指一個一個點過去，數到幾就是幾度。

練十次，孩子的手指會自動從「一」開始。

## 大三度和小三度：同樣是三度，差半音

單元的第三個觀念是音程的種類。這一段國小可以先知道有這件事，不用深。

同樣叫三度，有大有小：
- **C 到 E**：大三度。中間有四個半音。
- **C 到 E♭**：小三度。中間有三個半音。

數音名的時候兩個都是「C D E」三個，所以都是三度；但實際的距離差了半音，所以一個大一個小。

聽起來的差別：大三度明亮、小三度柔和。這其實就是大調和小調的差別——大調的第三個音是大三度，小調的是小三度。孩子如果之前學過 C 大調那一課，這裡會連起來。

國小階段：**先會數度數，大小等進階。** 數度數只看白鍵、只看音名；大小要算半音，需要黑鍵的概念。

## 協和與不協和：用聽的

第四個觀念是協和與不協和。這個最好用聽的，不用講理論。

兩個音一起彈：
- **協和**：聽起來融合、穩定、舒服。八度、五度、三度、六度。
- **不協和**：聽起來緊張、有點刺、想要「走到別的地方」。二度、七度。

在鍵盤上試：C 和 G 一起按（五度）——很和諧。C 和 D 一起按（二度）——有點擠。C 和 B 一起按（七度）——很想動。

跟孩子說：**不協和不是「不好聽」，是「還沒結束」的感覺。** 音樂需要不協和來製造緊張，再用協和來解決——就像故事需要衝突再需要結局。全部都是協和的音樂會很無聊。

孩子聽出這個差別之後，聽音樂會多一層：他會聽到「這裡在緊張、這裡放鬆了」。

## 音程在哪裡會用到

- **唱歌**：看譜唱，要知道下一個音比這個音高幾度，才唱得準。
- **和弦**：下一課的和弦就是音程疊起來的——大三和弦是大三度加小三度。音程沒穩，和弦會聽不懂。
- **聽力**：音樂班的聽寫考音程，聽兩個音說幾度。

所以音程是一個「工具課」——它本身不是目的，是後面很多東西的基礎。

## 在家怎麼練

1. **鍵盤數度數**：你說兩個音，孩子在鍵盤上一個一個點，數出度數。從 C 開始，只用白鍵。十題。
2. **反過來**：你說「從 C 往上五度」，他找到 G。
3. **聽協和不協和**：你彈兩個音，他說「舒服」還是「緊張」。不用說度數。
4. **做題**：[樂理練習](https://learn.chparenting.com/music)的音程題目，做完看解說。

前三步不需要會彈琴，有鍵盤就行。第一步練到手指自動從「一」開始，這一課就過了一半。

## 音程這一課常見的三個錯

- **從 0 開始數**：C 到 E 算成二度。回到「數樓層不是數樓梯」，手指在鍵盤上點三個鍵。
- **往下數的時候反過來**：E 到 C 也是三度，方向不影響度數。孩子往下數會亂，先只練往上。
- **把黑鍵算進去**：C 到 E 中間有兩個黑鍵，孩子算成五度。度數只數音名（白鍵的名字），黑鍵是大小音程的事，國小先不算。

三個錯裡第一個最普遍，也最容易改——手指點過幾次就好。
