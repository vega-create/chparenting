孩子學鋼琴半年，一直彈 C 大調的曲子，彈得很順。然後有一天拿回一首新曲子，譜的開頭多了一個 ♯，他每次彈到 F 都彈錯。

老師說「這是 G 大調，F 要升」。他點頭，但不懂為什麼。

**這是很多孩子第一次真正卡住的地方——不是手的問題，是他不知道「調」是什麼。** 這篇從 C 大調開始講音階、調號、大調小調，讓孩子在遇到第一個升記號之前先有概念。

## 先講音階：一組排好的音

[樂理的音階與調性單元](https://learn.chparenting.com/music/basic/scales)講的第一件事是：什麼是音階。

音階就是**一組音照高低順序排好**。最熟悉的就是 Do Re Mi Fa Sol La Si Do——七個音往上走，第八個回到高一個八度的 Do。

跟孩子講：音階是一首曲子的「材料」。就像做菜有食材，一首曲子用的音大部分都從一個音階裡來。知道這首曲子用哪個音階，就知道大概會用到哪些音。

## C 大調：為什麼全是白鍵

單元的解說裡有一句很關鍵：**C 大調是唯一沒有任何升降記號的大調，全部使用白鍵。**

從鍵盤上的 C 開始，只彈白鍵往上走：C D E F G A B C。這就是 C 大調音階。不用碰任何黑鍵。

為什麼剛好全白鍵？因為大調音階有一個固定的「距離排法」：**全、全、半、全、全、全、半**。全是全音（中間隔一個鍵），半是半音（緊鄰的鍵）。從 C 開始照這個排法走，每一步剛好都落在白鍵上——E 和 F 之間、B 和 C 之間本來就是半音（中間沒有黑鍵），其他地方是全音。

從別的音開始走同樣的排法，就會踩到黑鍵。這就是為什麼**只有 C 大調全白鍵**，也是為什麼初學都從它開始。

## 從 G 開始走：第一個升記號從哪來

現在可以解釋孩子卡住的那首曲子了。

從 G 開始，照「全全半全全全半」走：G A B C D E **F♯** G。走到第七個音的時候，要是全音，F 不夠，要 F♯（F 右邊的黑鍵）。

所以 G 大調有一個升記號：F♯。譜的開頭那個 ♯ 就是在說「這首曲子裡所有的 F 都升」。

孩子用鍵盤走一次就懂了：從 G 開始，數「全全半全全全半」，走到 F 的時候發現距離不對，要往上一格。**他自己走出那個 F♯，比老師告訴他「F 要升」有用一百倍。**

## 調號：寫在開頭的「本曲通用規則」

譜開頭的升降記號叫**調號**。它的意思是：「這首曲子裡，這幾個音全部都要升（或降）。」

調號告訴你這首曲子是什麼調——沒有升降是 C 大調、一個升是 G 大調、一個降是 F 大調。國小階段遇到的大概就這三個。

跟孩子講調號的方法：**它是「本曲通用規則」，寫在門口，進去之後全部適用。** 看到一個 ♯ 在 F 的位置，就知道進去之後每個 F 都升，不用每次寫。

## 大調和小調：明亮和陰暗

單元裡還有大調和小調的差別。孩子不用懂理論，用聽的：

- **大調**聽起來明亮、開心。「生日快樂歌」是大調。
- **小調**聽起來比較暗、比較憂鬱或神秘。很多電影配樂的緊張段落是小調。

差別在音和音之間的距離排法不同——小調的第三個音比大調低半音，就那一點差別，整個感覺就變了。

讓孩子聽兩首歌，一首大調一首小調，問他「哪一首比較開心？」他答得出來。這就是對調性的第一個感覺。理論等他問「為什麼」再說。

## 關係大小調：共用一套調號

單元最後提到「關係大小調」。這對國小生有點深，但有一個很簡潔的說法可以先種下：

**每個大調都有一個小調跟它共用同一套調號。** C 大調沒有升降，A 小調也沒有升降——它們是關係大小調。同一組材料（同樣的白鍵），從 C 開始走是大調、從 A 開始走是小調。

孩子在鍵盤上試：從 C 走白鍵到 C，明亮；從 A 走白鍵到 A，陰暗。同樣的鍵，不同的起點，不同的感覺。這個實驗會讓他對「調」有很深的印象。

## 在家怎麼練

不需要孩子會彈琴，有鍵盤（或手機上的鍵盤 app）就好：

1. **走 C 大調**：從 C 只彈白鍵到 C，邊彈邊唱 Do Re Mi。三次。
2. **數距離**：邊走邊說「全、全、半、全、全、全、半」，看 E-F 和 B-C 的地方為什麼是半。
3. **從 G 走**：照同樣的距離走，自己找到 F♯。
4. **聽大小調**：從 C 走一次、從 A 走一次，說哪個亮哪個暗。

四步各幾分鐘。第三步是重點——自己走出第一個升記號的孩子，之後看到調號不會怕。

## C 大調之後：第二個調怎麼選

C 大調穩了之後，下一個調通常是 **G 大調**（一個升記號 F♯）或 **F 大調**（一個降記號 B♭）。為什麼是這兩個？因為它們離 C 大調最近——只差一個記號。

順序建議 G 大調先。理由是上面講過的：孩子可以自己用「全全半全全全半」從 G 走出 F♯，那個「自己走出來」的經驗很重要。F 大調的 B♭ 是往下降，方向不同，等 G 大調穩了再來。

每多一個調，孩子的「調號感」就多一層。到了三四個升降記號的調（D 大調、A 大調、E♭ 大調），他已經不會怕了——因為他知道調號只是「本曲通用規則」，多幾個而已。

## C 大調的曲子為什麼聽起來「最普通」

孩子有時候會問：為什麼老師說 C 大調最簡單，但很多好聽的歌都不是 C 大調？

因為「簡單」是指手指——全白鍵好彈；「好聽」是另一件事。不同的調有不同的色彩，有些人覺得 E♭ 大調溫暖、D 大調明亮。而且歌手會選適合自己音域的調來唱，不會為了好彈選 C 大調。

跟孩子說：C 大調是「學走路的地方」，不是「只能走的地方」。走穩了，每一個調都可以去。
